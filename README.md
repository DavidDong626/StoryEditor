# 叙事工坊 · 游戏剧情编辑器

依据 [设计文档](docs/剧情编辑器设计文档.md) 开发的可视化剧情工作台。

当前为 **v0.2 协作 Alpha**：保留本地创作，新增 2–5 人协作服务、账号邀请、实时更新、对象占用、权限、冲突草稿与服务端快照。公网协作需要部署服务，步骤见 [远程协作说明](docs/远程协作部署与使用.md)。

## 启动

需要 Node.js 24 LTS（本次使用 24.18），推荐 Chrome/Edge 桌面浏览器。

```sh
npm ci
npm run dev:all
```

打开 http://127.0.0.1:5173/，点击“远程协作”，注册或登录，再将本地项目发布到协作服务。所有者生成邀请链接，成员登录后接受邀请。服务端默认监听 3001；前端代理 API 与 WebSocket。这里只监听本机，公网部署使用 Docker Compose + HTTPS。

```sh
npm test          # 运行语义、数据校验与存储测试
npm run build    # 类型检查及生产构建
npm run preview  # 本机预览生产构建
npm run backup   # 对正在运行的服务生成完整 SQLite 备份
```

## 已实现

- 中文工作台、章节目录、多个场景、项目切换与空白/示例项目创建。
- 起点、剧情、选择、条件、跳转、结局六类节点；拖动连线、拖动节点、框选、复制子图、删除与撤销/重做。
- 正文及角色对白，角色资料与稳定引用，内容状态管理。
- 项目变量（布尔、数值、字符串）、单项条件、顺序分支与兜底、设值/增加/减少效果。
- 固定版本试跑、变量调试、路径记录、退回恢复、100 步自动循环保护。
- 全文搜索、类型筛选、结构与引用检查、问题定位。
- IndexedDB 事务保存，失败提示与重试、手动快照、恢复前安全快照。
- 创作备份 JSON 下载/导入新项目，运行 JSON 导出及错误阻断。
- 同一浏览器第二个标签页只读，防止本地数据相互覆盖。

## 使用

角色头像：在角色列表选择角色，点击“导入头像”。支持 PNG、JPEG、WebP（原图最大 5 MB），自动居中裁为 256 × 256；可替换或移除。头像显示在角色列表、对白编辑和试跑中，随项目备份和协作同步保存。详见 [头像说明](docs/角色头像导入.md)。

首次打开自带“雾港来信”示例：帮助守卫获得钥匙后进入仓库；直接前往仓库则会遇到上锁的门，可以返回或离开。

点击节点在右侧编辑内容。从出口圆点拖向目标入口建立连线；双击连线删除。跨场景通过“跳转”节点指定目标。试跑始终使用打开时的项目快照，调试变量不会改默认值。

| 快捷键 | 行为 |
|---|---|
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做当前会话自己的修改 |
| Ctrl+D | 复制选中子图（不复制外部连线；跳转引用保留） |
| Delete / Backspace | 删除选中节点并确认影响 |
| Shift / 空白框选 | 多选 |
| 空格拖动 / 中键拖动 | 平移 |
| F | 适应选中内容或整个场景 |
| Esc | 关闭当前对话框或取消选中 |

输入文字和中文输入法合成时，画布快捷键不会生效。初次进入场景优先显示前几个节点；通过缩略图、平移或 F 查看全图。

## 保存与边界

数据存在当前浏览器、当前地址的 IndexedDB 中；换浏览器、换端口或清理站点数据不会保留原内容。重要修改后请导出创作备份。快照不是独立备份；撤销和操作记录只保留当前会话。只有存储事务完成后才显示“已保存到本机”。

本地模式使用 Web Locks 保证只有一个标签页可写；不支持 Web Locks 的环境仅提供只读。第二标签页能接收同浏览器保存通知，但这是本地查看同步，不是团队远程协作。

协作模式以服务端为事实来源。节点点击“开始编辑”后占用，其他成员只读；结构修改也会校验关联节点。不同对象的修改合并，同一对象的旧版本拒绝提交。断线重连获取最新版本，冲突稿保存在独立 IndexedDB 中，可以下载后手动合并。服务端保存操作日志和命名快照；恢复前自动备份并递增 epoch。协作撤销仅针对自己的、未被后续修改触及的对象；暂不支持协作重做。

当前采用 SQLite WAL 单实例部署，PostgreSQL 迁移、每日自动快照、增量事件补拉、字段差异合并、AND/OR 条件分组、引擎适配和 P1 评论仍待实现。实时通知和重连采用完整权威快照；未完成跨网络 5 人与 300 节点性能验收。详见 [开发进度](docs/开发进度.md)。

## 代码结构

```text
src/core/          领域模型、结构检查、运行解释器、导入导出、浏览器存储
src/components/    节点卡片、属性面板、逻辑表单、试跑、应用内对话框
src/App.tsx        工作台及本地编辑命令调度
server/            账号、权限、对象租约、事务命令、WebSocket、快照与备份
deploy/            HTTPS 反向代理配置
src/styles.css    工作台与响应布局
docs/              设计基线、开发进度与验收记录
```

所有剧情执行规则都在 core 中，后续服务端复用校验与解释器。新需求先修改设计基线，再更新实现和语义测试；运行导出是自定义格式，不宣称与 Arcweave 或游戏引擎插件兼容。
