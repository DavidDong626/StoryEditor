# 开发进度与验收记录

日期：2026-10-11 · 当前里程碑：v0.2 协作 Alpha

设计文档仍为产品基线。本版接通单实例远程协作服务，保留浏览器本地项目；服务已在本机运行，尚未发布公网地址。

## 已实现

- Node.js / Express 服务、SQLite WAL 持久化，项目与操作日志在同一事务提交后返回确认并广播。
- 账号名注册及登录，scrypt 加盐密码、HttpOnly / SameSite 会话、来源检查、登录限流；生产 HTTPS 使用 Secure Cookie。
- 项目所有者 / 编辑者 / 查看者，所有 API 与 WebSocket 订阅检查成员权限。查看者不能写入或通过导出接口导出。
- 发布本地项目为独立服务端副本；24 小时单次邀请；最多 5 位成员；移除成员立即关闭连接，所有者不可被降权或移除。
- 按对象差量命令、预期版本与修改前值校验、operationId 幂等、单调 revision、恢复 epoch。
- 节点显式开始 / 结束编辑，租约 30 秒、每 10 秒续租；客户端会话绑定及 fencing token。连线修改占用两端节点，服务端再次检查整个项目引用和类型。
- WebSocket 在线成员、占用状态、实时权威项目推送；断线停止编辑，自动重连获取最新完整快照。
- 未确认修改写入独立 IndexedDB；冲突保留最新完整草稿，停止后续提交，支持下载和手动合并，不自动覆盖远端。
- 服务端命名快照、恢复前安全备份；恢复使用 revision 确认及 epoch 失效旧命令，不恢复成员权限。
- 固定 revision 的服务端运行导出与创作备份；自己的对象级撤销，拒绝覆盖后续修改；协作重做暂不提供。
- Docker Compose + Caddy HTTPS 配置、持久化卷、运行中数据库一致性备份脚本。

## 对设计基线的实现差异

| 基线 | 当前实现与边界 |
|---|---|
| PostgreSQL | SQLite WAL + 单 Node 实例。当前环境无 PostgreSQL / Docker，采用本机可运行方案；没有 PostgreSQL 适配器，也不支持多实例。 |
| 实时增量事件 / 重连补拉 | 事务日志持久化；实时通知及重连下发完整权威快照。客户端按 revision 避免倒退。300 节点性能仍需实测。 |
| 成熟身份方案 | 当前为账号名 + Node 标准 scrypt + 不透明会话；没有第三方身份集成、邮箱验证、找回密码或登录管理后台。 |
| 自动保存停顿提交 | 每次有效修改排队提交；未确认稿先写入独立 IndexedDB。尚未加入输入停顿合并。 |
| 协作撤销 / 重做 | 撤销一条自己的服务端命令；后续写入触及对象即拒绝。尚不支持跨刷新撤销栈、连续撤销依赖重排、协作重做。 |
| 自动快照、字段差异、恢复演练 | 命名快照、恢复前快照及一致性数据库备份已接通；每日自动调度、字段差异合并界面仍待实现。 |
| 2–5 人跨网络验收 | 独立会话接口测试与双浏览器客户端联调通过；没有公网部署，未做两条真实网络或 5 人性能验收。 |

SQLite 是本阶段明确的技术差异，不表示原文中的 PostgreSQL 已完成。当前可靠性保证依赖单服务实例、数据库本地持久化卷及所有写入经过该服务。

## 本次验证

自动测试共 41 项，包括 21 项既有剧情 / 本地存储 / 角色头像检查及 20 项协作检查：不同节点并发合并、同一节点互斥、租约释放和 30 秒超时后的过期 token、同账号跨登录会话隔离、ABA 版本冲突、重复命令幂等、只读与未授权读取 / 订阅 / 导出、邀请复用与 5 人上限、权限移除、快照恢复 epoch 和备份、自己的撤销、数据库重启持久化、客户端连续输入排序、最新冲突稿保留和断线禁止提交。

浏览器联调：注册本机测试账号，发布“雾港来信”示例；两个独立客户端打开同一协作项目；第一个客户端占用节点并修改标题，第二个客户端实时看到更新且该节点编辑按钮禁用；刷新后重新打开同一服务端项目。此测试使用本机和同一账号两个客户端，不替代多人跨网络验收。

TypeScript 与生产构建通过。一致性备份命令已实际生成数据库文件。Docker 配置已提供，但当前环境没有 Docker，未声称容器部署实测通过。
