# 角色头像导入

角色列表中选择角色，或打开“角色资料”，点击“导入头像”。支持 PNG、JPEG、WebP，原图不超过 5 MB；图片会居中裁为正方形并压缩至 256 × 256，透明背景保留。可替换或移除头像；未设置头像时继续显示角色名称的首字。

头像显示在侧栏角色列表、角色资料、对白编辑和剧情试跑中。试跑采用打开时的项目版本，因此修改头像后重新打开试跑即可看到新头像。

数据模型新增可选 `Character.avatar`，内容是经过图片解码和重编码的 data URL，支持 PNG、JPEG、WebP，字段上限 350,000 个字符。旧项目和旧备份不需要迁移；创作备份和运行导出均保留头像，角色 ID 与已有对白引用保持不变。协作模式通过角色对象的版本校验和租约提交头像，其他在线成员收到服务端确认后的头像。

头像嵌入项目，便于小团队自部署和离线备份；本阶段不新增素材对象存储。不支持 GIF、SVG、外链头像或手动裁剪框。将来增加大图素材库时，应另行设计附件存储与生命周期，避免扩大剧情命令和备份文件。

验证：实际浏览器导入 320 × 240 PNG 后得到 256 × 256 头像；刷新仍保留，另一个协作客户端能显示同一头像；移除会同步到另一客户端，重新导入后试跑对白也显示头像。单元测试覆盖格式识别、超限拒绝、旧项目兼容、备份往返与运行导出保留。
